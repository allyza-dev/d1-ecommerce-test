# Installation & Setup

1. Clone the repository:

```bash
  git clone https://github.com/allyza-dev/d1-ecommerce-test.git
  cd d1-ecommerce-test
```

2. Checkout branch

```bash
  git checkout dev
```

3. Install dependencies (Foundation + Sass compiler)

```bash
  npm install
```

4. Finally, run `npm start ` to run the project.
